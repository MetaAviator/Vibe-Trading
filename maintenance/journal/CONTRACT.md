# 首版输入合同 v0.1 · 工程基线

状态：本轮新定义的交易工程合同；真实平台映射和源文件尚待逐项核对。它与现有date,ticker,close行情格式是不同输入类型。USD美股现货是建议的首版范围，不是已经确认的真实账户范围。

## CSV列与单位

| 列 | 要求 |
|---|---|
| execution_id | 来源内唯一成交ID；缺失时身份可信度待验证，不能自动去重 |
| datetime | 可明确解析的成交时间；必须记录来源时区和同时间戳顺序依据 |
| symbol | 美股标的代码；原始代码及映射可追溯 |
| side | buy或sell；不把不明方向猜成买入 |
| quantity | 有限正数量，单位为股，允许来源支持的小数股 |
| price | 有限成交单价，USD/股；工程校验不证明价格经济合理 |
| amount | 同币种毛成交额；与quantity×price差额按来源舍入合同核对 |
| fee | 该笔全部已确认交易费用，USD；允许有限负返佣，明确0须有依据 |
| currency | USD；首版不混币种，不自动换汇 |

UTF-8 CSV为规范化交付格式。上游generic parser不会保存execution_id/currency的完整来源语义，验收账本须另保留ID到源行映射并核对symbol推断币种；这不等于新增了自动账户对账能力。

## 不可省略的来源说明

记录平台/导出版本、账户代号、期间/时区、毛额与净额口径、费用是否完整且同币种、期初期末持仓、期间分红/转账/换汇。缺失或不明费用标为unknown，不把parser的兼容0当成真实0。不将Commission+Platform Fee未经核对视为完整券商总成本。

同一文件出现重复ID、未知币种、无法解释的金额差异或未确认持仓边界时，真实验收不通过。原始文件只读；不删除成交腿、不补价格/费用、不按行内容自动去重。

## 账本与指标

对期初期末空仓且无其他现金事件的单币种样本，独立净交易现金=卖出毛额−买入毛额−全部交易费用。将每笔成交和每次配对的费用分摊核对，不能只看最终总额。

胜率按FIFO匹配片段净PnL>0计数；不是交易决策级胜率。平均盈亏比为平均正净现金PnL/平均负净现金PnL绝对值，无亏损时不制造有限比率。账户收益率、未实现盈亏和R单位不在首版定义中。

真实币种/平台舍入规则必须在核对前确认。合成验收的0.01金额展示/ROUND_HALF_EVEN只是测试约定，不自动成为券商结算规则。
